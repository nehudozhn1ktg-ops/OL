# OneLife — рабочий репозиторий

Настольная игра, которая переезжает в пошаговый онлайн PvP.
Здесь живут правила, код, арты и «память» проекта.

## Если ты человек и зашёл впервые

Читать в таком порядке — 10 минут:

1. **`docs/memory/context.md`** — что происходит сейчас, что уже есть,
   что делаем дальше. Обновляется каждую сессию.
2. **`docs/memory/decisions.md`** — все решения по правилам с датами и цитатами.
   Если что-то в игре спорно — ответ скорее всего здесь.
3. **`docs/memory/errors.md`** — что сломано, что непонятно, какие вопросы
   ждут ответа. Раздел «Открытые» — это то, где нужен человек.
4. **`docs/canon/`** — сами правила, разложенные по главам.
5. **`AGENTS.md`** — правила, по которым работают агенты (и люди).

Ничего устанавливать не нужно: все файлы — обычные markdown, читаются
в браузере на GitHub.

## Как устроена работа

Проект ведут два человека и несколько ИИ-агентов. Агенты не помнят прошлый
разговор — они помнят только файлы в этом репозитории. Поэтому:

- решение, не записанное в `decisions.md`, считается несуществующим;
- вопрос, не записанный в `errors.md`, будет задан повторно;
- состояние, не записанное в `context.md`, будет потеряно при следующем сбросе.

Это не бюрократия, а замена человеческой памяти: переписка с агентом живёт
один сеанс, файл — сколько угодно.

## Структура

```
project.godot          корень проекта Godot 4.7
scenes/main.tscn       стартовая сцена — гексагональное поле
scripts/               GDScript (hex_grid.gd — отрисовка, rules/ — правила)
tests/                 headless-тесты правил
assets/                арты и иконки
docs/canon/            действующие правила по главам
docs/memory/           context.md, decisions.md, errors.md
docs/architecture.md   почему Godot и как устроена сеть
agents/roster.md       пять ролей: кто что делает
AGENTS.md              правила для агентов
```

## Запуск

Нужен Godot 4.7.2 (обычная сборка, не .NET): файл вида
`Godot_v4.7.2-stable_win64.exe`. Положить, например, в `C:\Godot\`, затем:

```powershell
C:\Godot\Godot_v4.7.2-stable_win64.exe --path .        # запустить игру
C:\Godot\Godot_v4.7.2-stable_win64.exe --path . --headless --quit   # проверить, что проект цел
C:\Godot\Godot_v4.7.2-stable_win64.exe --headless --path . --script res://tests/verify_hex.gd   # тесты геометрии
C:\Godot\Godot_v4.7.2-stable_win64.exe --headless --path . --script res://tests/rules_board.gd  # тесты правил
```
