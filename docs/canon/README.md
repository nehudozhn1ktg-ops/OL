# Канон правил

Здесь лежит **действующая редакция правил** — то, по чему можно писать код
и разрешать спор. Всё, что здесь есть, прошло через `docs/memory/decisions.md`.

## Порядок старшинства

1. `docs/canon/` — если написано здесь, это правда.
2. `docs/memory/decisions.md` — решения владельца, ещё не разнесённые по главам.
3. Исходные документы (docx 0.7.1, патч 7, FAQ) — черновик, может противоречить сам себе.
4. Код и тесты — отражение, а не источник.

## Структура (заполняется по мере переноса)

| Файл | Содержание | Статус |
|---|---|---|
| `01-board.md` | поле, террейны, легенда, иконки | не начат |
| `02-turn.md` | порядок хода, очки, фазы | не начат |
| `03-units.md` | фигуры, статы, способности | не начат |
| `04-factions.md` | фракции и их состав | не начат |
| `05-combat.md` | атака, защита, раны, смерть | не начат |
| `06-auras.md` | ауры, зоны, момент пересчёта | не начат |
| `07-edge-cases.md` | вода, форт, обмен, 2×2 | частично (см. ADR) |

## Правило переноса

Одна глава = один документ = одна задача для агента. Переносим не «весь текст»,
а **проверенные утверждения**: каждое — с ссылкой на источник (страница docx
или пункт FAQ). Непроверенное остаётся в исходниках и в `errors.md`.
