## Открытые

### OPEN_QUESTION-004 — классы фигур в undead.json проставлены на глаз
При переносе нежити поле `kind` я заполнил без проверки значка внизу карты.
Например, у Некроманта на карте корона, а в данных он `pawn`. Правильно
определять класс только по значку: корона — king, рыцарский шлем — commander,
шеврон — pawn. Проверка поручена отдельному проходу; до неё классы нежити
считать недостоверными.

### KNOWN-002 — git не виден в шелле агента
В пользовательском PATH `C:\Git` есть, но в оболочке инструментов `git`
не находится (`CommandNotFoundException`). Обход: звать полным путём
`C:\Git\cmd\git.exe` или начинать команду с `$env:Path = "C:\Git\cmd;" + $env:Path`.

### ASSUMPTION-001 — клетка уничтоженного флага
Канон: «После уничтожения флаг убирается с поля», но не сказано, остаётся ли
клетка препятствием. В коде (`Game._remove_flag`) клетка становится
`TERRAIN_GRASS` и проходимой; тест `tests/flag.gd` фиксирует это как
«клетка стала свободной (ASSUMPTION)». Вопрос владельцу:
А — клетка проходима, Б — остаётся непроходимой (флаг снят, но подложка мешает).
