## UI геймплея (записано 2026-11-16, от владельца) — DONE 2026-11-16

- [x] **Плашка действий у фишки.** Кнопки «передвижение / атака / действие» и
  характеристики рисуются плашкой рядом с гексом выбранной фигуры.
- [x] **Характеристики с источником.** Урон/броня/движение с разложением бонуса
  (броня фигуры, лес/укрепление, аура, усиление биомассой).
- [x] **Ховер по тайлу.** Плашка с эффектом террейна.
- [x] **Ховер по тайлу с фигурой.** Показываются и фигура, и тайл.

Реализация: `scripts/hex_grid.gd` (`terrain_effect`, `figure_screen_pos`,
сигнал `tile_hovered_changed`) и `scripts/hud.gd` (плашка `_actions` у фигуры,
`_stat_lines` с источниками, объединённый тултип тайл+фигура, счётчик ресурса).
Проверено снимком `-- --shot` и OCR.
