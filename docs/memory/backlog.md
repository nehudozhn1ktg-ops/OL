# Бэклог задач (OneLife)

Живой список задач, которые не помещаются в «следующий шаг» контекста. Одна
задача = один шаг. Статусы: `TODO` / `WIP` / `DONE`.

## UI геймплея (записано 2026-11-16, от владельца)

- [ ] **Плашка действий у фишки.** При выборе своей фигуры кнопки
  «передвижение / атака / действие» рисуются плашкой **рядом с её гексом**, а не
  на правой панели.
- [ ] **Характеристики с источником.** Рядом с фишкой — актуальные значения
  урона/брони/движения с припиской, откуда бонус (способность фигуры, лес,
  укрепление, аура, биомасса). Сейчас это строка сверху без разложения на
  слагаемые.
- [ ] **Ховер по тайлу.** При наведении на клетку — плашка с эффектом террейна
  (лес +1 защита при атаке в упор; укрепление +1 защита и реакция; ключевая
  точка — очки; вода непроходима и т.д.).
- [ ] **Ховер по тайлу с фигурой.** Если на клетке стоит фигура — плашка
  показывает **и фигуру, и тайл** одновременно.

Затрагивает: `scripts/hex_grid.gd` (поле, выбор, подсветка, тултип),
`scripts/hud.gd` (правая панель и строка характеристик). Для «источника бонуса»
нужно раскладывать `Game.defense_bonus` / `attack_bonus` /
`terrain_defense_bonus` / `aura_defense_bonus` на именованные слагаемые.
